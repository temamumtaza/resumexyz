# Resume Quality Gate

Use this as the internal checklist for deciding whether the agent has enough
material to generate a strong resume.

---

## Evidence ladder

Prefer evidence in this order:

1. **Measured impact** — %, $, time saved, volume, users, customers, revenue,
   cost, accuracy, speed, quality, adoption, retention, conversion.
2. **Scope** — team size, stakeholder count, regions, channels, locations,
   transactions, tickets, reports, campaigns, events, accounts.
3. **Project proof** — problem, method, tools, output, outcome.
4. **Ownership** — owned process, trained others, led initiative, coordinated
   cross-functionally, presented results, handled escalation.
5. **Tool specificity** — exact tools, platforms, frameworks, methods.
6. **Responsibilities** — use only when connected to any item above.

---

## Strong follow-up probes

Use one at a time.

| Missing signal | Ask |
|----------------|-----|
| Outcome | "What changed after you did that?" |
| Number | "Can you estimate the scale, even roughly?" |
| Tool | "What tools, software, systems, or methods did you use?" |
| Project | "What was one concrete project or initiative from that role?" |
| Method | "How did you approach it or what steps did you take?" |
| Output | "What did you actually produce: report, dashboard, process, campaign, feature, event, document, analysis?" |
| HR proof | "Did anyone use it, approve it, praise it, adopt it, or rely on it?" |
| Leadership | "Did you train, coordinate, present, own, or improve anything for others?" |

---

## Early-career booster

For fresh graduates, students, juniors, and career pivots, ask for:

- Capstone, thesis, coursework, lab, or case study projects
- Internship projects and measurable outputs
- Campus organization leadership or event ownership
- Competition, award, scholarship, publication, portfolio, GitHub
- Freelance, family business, volunteer, part-time work
- Certifications with projects or assessments attached

Promote these only when they prove the target role better than generic work
history.

---

## Do not proceed when

- Recent role has only duties and no project, scope, tool, or outcome.
- User gives tools but no context of how they used them.
- Fresh grad/junior has no project, internship, campus achievement, or practical proof.
- Bullets would need invented metrics to sound strong.
- Summary would rely on generic phrases like "hardworking" or "passionate".

Ask another targeted question instead.
