# Reference: Bullet Writing Guide

Used by `agents/builder-agent.md` when transforming raw user input
into recruiter-ready experience bullets.

---

## The core formula

```
[Strong action verb]  +  [what you did or owned]  +  [measurable result or scope]
```

Every bullet must answer the question: **"So what?"**

If the bullet ends without answering that — if a recruiter could read it
and think "okay, and?" — it needs another clause.

---

## Bullet count and order

| Role recency | Bullets |
|-------------|---------|
| Most recent role | 5–6 |
| Second most recent | 4–5 |
| Older roles | 3–4 |
| Roles 10+ years ago | 2–3, or omit |

**Order within a role (most important first):**
1. Highest-impact / most quantified achievement
2. Strategic or leadership contribution
3. Execution or delivery accomplishment
4. Cross-functional or collaborative work

Recruiters read the first bullet most carefully. Put the best one there.

## Action verbs by impact category

### Leadership and ownership
Led, Managed, Directed, Oversaw, Owned, Spearheaded, Championed,
Mentored, Coached, Supervised, Orchestrated, Mobilized

### Building and creating
Built, Designed, Developed, Created, Launched, Established, Founded,
Architected, Engineered, Produced, Authored, Deployed

### Improving and optimizing
Optimized, Improved, Streamlined, Transformed, Modernized, Revamped,
Enhanced, Refined, Accelerated, Reduced, Cut, Eliminated, Simplified

### Growing and scaling
Grew, Scaled, Expanded, Increased, Doubled, Tripled, Boosted, Drove,
Generated, Secured, Achieved, Surpassed

### Executing and delivering
Executed, Delivered, Implemented, Rolled out, Completed, Coordinated,
Facilitated, Administered, Managed, Oversaw

### Analyzing and reporting
Analyzed, Evaluated, Assessed, Audited, Monitored, Reported, Tracked,
Synthesized, Modeled, Forecasted, Identified

### Partnering and influencing
Partnered, Collaborated, Aligned, Negotiated, Presented, Advised,
Consulted, Liaised, Influenced, Secured buy-in

## Quantification guide

Numbers are the most compelling signal on a resume. When the user does not
have exact figures, use these patterns — but never fabricate:

| User provides | How to write it |
|---------------|----------------|
| Exact number | Use it: "reduced churn by 18%" |
| Approximate number | "reduced churn by approximately 20%" |
| Vague description | Use scope: "managing a team of 8 across 3 time zones" |
| No number at all | Use significance: "presented findings to C-suite quarterly" |
| Budget range | "overseeing a $400K–$600K annual budget" |
| Volume | "supporting 200+ enterprise accounts" |
| Time | "compressing a 6-week process to 10 days" |

If a critical number is truly unknown, note it when delivering the resume:
> "For the [role] bullet about [topic], I used approximate language —
> if you can recall the actual number, I'd swap it in."

## What to always rewrite

| Pattern | Why | Fix |
|---------|-----|-----|
| "Responsible for X" | Describes a job description, not an achievement | "Led/Managed X, resulting in [outcome]" |
| "Helped with X" | Undersells contribution | "Collaborated on X to [achieve outcome]" |
| "Was involved in X" | Passive and vague | "Contributed to X as [specific role or function]" |
| "Worked on X" | Neutral — no verb, no impact | "Built/Designed/Executed X, [result]" |
| Passive voice throughout | Weaker signal | Flip: "Reports were produced" → "Produced weekly reports" |
| Duty list without outcome | Looks like a job description | Add result clause: "...resulting in / contributing to / enabling" |
| Starting with a noun | Not ATS-optimized | Start with verb: "Campaign management" → "Managed campaigns" |

## Bullets that need a second clause

These bullet patterns are incomplete on their own. Add a result or scope:

| Incomplete | What to add |
|------------|------------|
| "Managed a team of 6" | "...across content, design, and paid media, shipping [X] campaigns per quarter" |
| "Led product roadmap planning" | "...for a platform with 120K monthly active users, prioritizing [X] features in Q3" |
| "Increased organic traffic" | "...by 45% in 6 months through technical SEO audits and content gap analysis" |
| "Reduced costs" | "...by $280K annually by consolidating 4 vendor contracts into a unified SaaS platform" |
| "Launched a new feature" | "...adopted by 60% of users within 30 days, contributing to a 12-point NPS increase" |
